저장 방식

기존 문제은행에서 새 버전으로 업데이트해도, 같은 기기의 브라우저에 저장된 오답 기록과 직접 수정한 문항은 가능한 범위에서 이어서 불러옵니다. 현재 기기 브라우저에 답변 상태·수정사항을 저장합니다. 다른 기기나 브라우저로 옮길 때는 JSON 백업 내보내기 후 가져오기를 사용하세요. 인터넷 없이 HTML 파일만 열어도 작동합니다.

질문을 보고 먼저 20~40초 동안 자신의 말로 답한 다음 정답을 여세요. 답변은 그대로 말할 수 있는 완성 문장이고, 꼬리질문도 문장형 답변과 이유를 함께 제공합니다.

자료 백업 / 복원

JSON에는 직접 추가·수정한 문제, 단원, 출처 정보, 풀이 상태가 모두 들어갑니다. 원본 JSON이나 이전 백업 파일도 불러올 수 있습니다.

자료 출처와 읽는 법

각 질문에 해당 자료와 페이지 또는 녹취 시각을 기록했습니다. 원본 강의의 문장 전체를 복제한 것이 아니라 개념을 풀이하기 위해 재구성했습니다. 기술 일반 설명이 추가된 경우에는 학습용 보충으로 표기합니다.
